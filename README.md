# Terraform AWS Infrastructure (lesson-5)

## Структура проєкту

- `main.tf` – підключення всіх модулів
- `backend.tf` – конфігурація бекенду S3 + DynamoDB
- `outputs.tf` – вивід ID ресурсів
- `modules/` – окремі модулі для кожного компонента

## Команди

```bash
terraform init
terraform plan
terraform apply
terraform destroy
```
## Опис модулів (Descripción de módulos)

### 1. `s3-backend`
Цей модуль створює інфраструктуру для зберігання стану Terraform:

- S3 bucket з увімкненим версіонуванням (versioning)
- DynamoDB таблиця для блокування стану (state locking)

#### Змінні:
- `bucket_name`: назва S3-бакету
- `table_name`: назва DynamoDB-таблиці

---

### 2. `vpc`
Модуль створює базову приватну мережеву інфраструктуру:

- VPC з CIDR-діапазоном `10.0.0.0/16`
- Публічні підмережі:
  - `10.0.1.0/24`
  - `10.0.2.0/24`
- Приватні підмережі:
  - `10.0.101.0/24`
  - `10.0.102.0/24`
- Internet Gateway (IGW) — для публічних підмереж
- NAT Gateway — для виходу приватних підмереж в Інтернет
- Маршрутні таблиці для зв’язку публічних і приватних підмереж з IGW та NAT

---

### 3. `ecr`
Модуль створює репозиторій у Amazon ECR (Elastic Container Registry):

- Ім’я репозиторію задається змінною `repository_name`
- Увімкнене сканування образів при завантаженні
- Повертає URL репозиторію для подальшого використання у CI/CD
